# Harici Binary Dosyaları
Uygulamanın taşınabilir (portable) çalışması için resmi kaynaklardan indirdiğiniz şu dosyaları bu klasöre (`bin/`) ekleyebilirsiniz:
1. `adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll` (Google Android SDK Platform-Tools)
2. `rclone.exe` (Rclone.org resmi sürümü)
3. `7z.exe`, `7z.dll` (7-Zip resmi sürümü - Şifreli oyun arşivlerini otomatik açmak için)
